// Component Reference

COMPONENT ROLE KEY COMMANDS / NOTES
⌨️ Docker Client Sends user commands to the Docker Daemon via REST API or Unix socket. docker build · docker run · docker pull · docker push
⚙️ Docker Daemon Core engine (dockerd). Manages containers, images, volumes, networks. Responds to Client API calls. Runs as background service · exposes /var/run/docker.sock
📋 Docker Compose Reads docker-compose.yml to define and run multi-container applications. docker compose up · docker compose down · docker compose build
☁️ Docker Hub Official public cloud registry hosted by Docker Inc. Millions of public images available. docker pull nginx · docker push user/image:tag · hub.docker.com
🗄️ Docker Registry Self-hosted private registry for storing images within an org or locally. docker run -d -p 5000:5000 registry:2 · configurable with TLS & auth
